Instruções para Rodar no Supabase

Como solicitado pelo cliente, todos os scripts SQL estão prontos no arquivo supabase/schema.sql. Para executar manualmente:

  1. Acesse o painel do seu Supabase: app.supabase.com
  2. Entre no menu SQL Editor na barra lateral esquerda.
  3. Clique em New Query.
  4. Copie todo o conteúdo do arquivo supabase/schema.sql e clique em Run.
  5. Todas as tabelas com RLS, triggers e índices serão geradas instantaneamente!
