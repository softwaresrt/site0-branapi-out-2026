Glossário Técnico de Engenharia

Glossário de engenharia de software, startups e sistemas web

Aprenda 40 termos essenciais de tecnologia, desenvolvimento de software, arquitetura de sistemas, APIs e startups explicados por quem programa na prática.

Por Equipe de Engenharia Branapi
Publicado em: 03 de novembro de 2026 Atualizado em: 03 de novembro de 2026 Padrão Técnico: ISO/IEC 25010 e LGPD

Consulte as definições práticas de 40 termos essenciais de tecnologia, engenharia de software e startups, elaborados pelos arquitetos da Branapi para esclarecer conceitos técnicos para líderes e fundadores.

1. MVP (Minimum Viable Product)

Definição: Versão mais enxuta de um produto que ainda entrega valor real ao usuário e permite validar hipóteses com dados práticos de mercado e baixo investimento.

Exemplo Prático: Lançar um app de agendamento que só faz marcação e pagamento online antes de desenvolver recursos avançados de telemedicina.

Ver serviço relacionado ↗

2. API (Application Programming Interface)

Definição: Conjunto de regras e protocolos que permite que dois sistemas de software diferentes se comuniquem e troquem dados de forma segura e automatizada.

Exemplo Prático: Seu sistema web envia uma solicitação para a API do banco e recebe a confirmação de que o PIX do cliente foi pago instantaneamente.

Ver serviço relacionado ↗

3. SaaS (Software as a Service)

Definição: Modelo de distribuição onde o software é hospedado na nuvem e acessado pelos usuários via navegador ou app, geralmente mediante assinatura recorrente.

Exemplo Prático: Plataformas como Notion, Slack ou um sistema de gestão escolar próprio que você aluga para outras empresas utilizarem.

Ver serviço relacionado ↗

4. ERP (Enterprise Resource Planning)

Definição: Sistema integrado de gestão empresarial que centraliza informações de finanças, estoque, compras, vendas, fiscal e recursos humanos em um único banco de dados.

Exemplo Prático: Um ERP sob medida que atualiza o estoque físico automaticamente assim que o vendedor emite um pedido no aplicativo mobile.

Ver serviço relacionado ↗

5. CRM (Customer Relationship Management)

Definição: Software voltado para o gerenciamento de relacionamento com clientes, funil de vendas, histórico de atendimentos e tarefas da equipe comercial.

Exemplo Prático: Um painel onde cada lead que chega pelo WhatsApp é registrado automaticamente com status de negociação e tarefas agendadas.

Ver serviço relacionado ↗

6. Front-end

Definição: Toda a interface visual, botões, animações e telas com as quais o usuário interage diretamente no navegador ou aplicativo.

Exemplo Prático: O layout em Next.js e Tailwind da Branapi com modo escuro, gráficos interativos e botões de chamada à ação.

Ver serviço relacionado ↗

7. Back-end

Definição: A estrutura de bastidores do sistema: servidores, lógica de negócio, processamento de cálculos e comunicação com bancos de dados.

Exemplo Prático: O código em Node.js ou Go que valida o CPF, processa o pagamento no gateway e grava a transação com segurança no banco.

Ver serviço relacionado ↗

8. Sprint

Definição: Ciclo de trabalho com duração fixa (geralmente de 1 a 2 semanas) no método ágil (Scrum), no qual um conjunto específico de funcionalidades é desenvolvido e testado.

Exemplo Prático: Na sprint 3 da Branapi, a equipe finalizou a tela de checkout e a integração do gateway de pagamentos.

Ver serviço relacionado ↗

9. Escopo de Software

Definição: Documento e acordo técnico que delimita exatamente quais funcionalidades, fluxos, regras de negócio e integrações farão parte do desenvolvimento.

Exemplo Prático: O escopo definiu que o sistema emitirá notas de serviço, mas a emissão de notas de produto ficou para a fase 2.

Ver serviço relacionado ↗

10. Código-fonte (Source Code)

Definição: Conjunto de instruções em linguagem de programação escritas por desenvolvedores que compõem o software. Quem detém o código é o proprietário do ativo.

Exemplo Prático: Na Branapi, todo o repositório Git com o código-fonte limpo e documentado é transferido 100% para a empresa contratante.

Ver serviço relacionado ↗

11. Banco de Dados Relacional (SQL)

Definição: Sistema de armazenamento de dados estruturado em tabelas com colunas e linhas que se relacionam entre si (ex: PostgreSQL, MySQL).

Exemplo Prático: Uma tabela de 'Clientes' conectada a uma tabela de 'Pedidos', garantindo integridade e evitando duplicidades financeiras.

Ver serviço relacionado ↗

12. Banco de Dados Não-Relacional (NoSQL)

Definição: Banco projetado para armazenar dados não estruturados ou semi-estruturados com alta velocidade de escrita (ex: MongoDB, Redis).

Exemplo Prático: Armazenamento do histórico de conversas em tempo real de um chatbot ou sessões de usuários ativos na plataforma.

Ver serviço relacionado ↗

13. Webhook

Definição: Mecanismo que envia dados em tempo real de uma aplicação para outra sempre que um evento específico acontece ('gatilho').

Exemplo Prático: Assim que o cliente paga um PIX, o gateway dispara um webhook para o seu sistema liberando o acesso do usuário na mesma hora.

Ver serviço relacionado ↗

14. Microserviços

Definição: Abordagem arquitetural onde uma aplicação é dividida em serviços menores e independentes que se comunicam por APIs.

Exemplo Prático: O serviço de autenticação funciona isoladamente do serviço de geração de relatórios; se um falhar, o outro continua no ar.

Ver serviço relacionado ↗

15. Monólito Modular

Definição: Arquitetura de software onde todo o sistema reside em uma única base de código, porém organizado em módulos estritamente isolados e testáveis.

Exemplo Prático: Abordagem recomendada para a maioria das empresas e startups, reduzindo a complexidade de servidores e acelerando entregas.

Ver serviço relacionado ↗

16. CI/CD (Continuous Integration / Continuous Delivery)

Definição: Automatização dos processos de teste, empacotamento e publicação do código em ambiente de produção sem intervenção manual propensa a erros.

Exemplo Prático: Cada commit aprovado passa por 50 testes automatizados e entra em produção em menos de 3 minutos na esteira de deploy.

Ver serviço relacionado ↗

17. Deploy

Definição: Ato de disponibilizar uma nova versão do software nos servidores para que os usuários finais possam acessá-la.

Exemplo Prático: Realizamos o deploy da versão 1.2 do aplicativo corporativo na nuvem AWS na noite de quinta-feira.

Ver serviço relacionado ↗

18. Cloud Computing (Computação em Nuvem)

Definição: Entrega de servidores, armazenamento, bancos de dados e redes pela internet (AWS, Google Cloud, Azure) com cobrança sob demanda.

Exemplo Prático: Sua plataforma aumenta os servidores automaticamente na Black Friday e reduz na semana seguinte, economizando custos.

Ver serviço relacionado ↗

19. LGPD (Lei Geral de Proteção de Dados)

Definição: Legislação brasileira (Lei nº 13.709/2018) que regulamenta o tratamento de dados pessoais de clientes e colaboradores em sistemas digitais.

Exemplo Prático: Implementação de consentimento explícito, logs de auditoria e criptografia para garantir que dados de saúde não vazem.

Ver serviço relacionado ↗

20. Autenticação em Dois Fatores (2FA)

Definição: Camada adicional de segurança que exige dois comprovantes de identidade para liberar o acesso ao sistema (ex: senha + código no celular).

Exemplo Prático: O gestor digita a senha no painel administrativo e precisa confirmar o código de 6 dígitos gerado no app autenticador.

Ver serviço relacionado ↗

21. SSG (Static Site Generation)

Definição: Técnica de compilação onde as páginas HTML são geradas antecipadamente no servidor, garantindo carregamento instantâneo e nota 100 em SEO.

Exemplo Prático: Todo o ecossistema do site da Branapi utiliza SSG para garantir que o Google rastreie 100% dos textos sem depender de JS no cliente.

Ver serviço relacionado ↗

22. SSR (Server-Side Rendering)

Definição: Técnica onde cada página é montada dinamicamente pelo servidor a cada requisição de um usuário, ideal para dados que mudam a cada segundo.

Exemplo Prático: Um painel de cotações financeiras ou feed de apostas esportivas em tempo real.

Ver serviço relacionado ↗

23. PWA (Progressive Web App)

Definição: Aplicação web que utiliza recursos modernos do navegador para oferecer experiência similar a um app nativo, incluindo ícone na tela inicial e modo offline.

Exemplo Prático: Um catálogo de pedidos para representantes comerciais que funciona mesmo sem sinal de internet na fazenda.

Ver serviço relacionado ↗

24. React Native

Definição: Framework desenvolvido pela Meta que permite criar aplicativos móveis para iOS e Android compartilhando até 90% da mesma base de código.

Exemplo Prático: Aplicativos como Instagram, Nubank e soluções corporativas da Branapi com alta performance e custo otimizado.

Ver serviço relacionado ↗

25. TypeScript

Definição: Superconjunto tipado de JavaScript que previne centenas de erros de digitação e lógica antes mesmo do código rodar em produção.

Exemplo Prático: Garante que uma função de cálculo financeiro nunca receba texto quando espera um número decimal de valor em reais.

Ver serviço relacionado ↗

26. Agente Autônomo de IA

Definição: Programa equipado com Modelos de Linguagem (LLMs) capaz de tomar decisões, consultar bancos de dados e executar ações sem intervenção humana.

Exemplo Prático: Um agente que atende o cliente no WhatsApp, consulta se o produto tem estoque, gera o link de PIX e atualiza o ERP.

Ver serviço relacionado ↗

27. LLM (Large Language Model)

Definição: Modelos de inteligência artificial treinados em grandes volumes de texto para compreender linguagem natural, resumir e redigir respostas (ex: GPT-4, Claude).

Exemplo Prático: Utilizado pela Branapi para interpretar dúvidas complexas de clientes e gerar resumos jurídicos automaticamente.

Ver serviço relacionado ↗

28. RAG (Retrieval-Augmented Generation)

Definição: Técnica que combina inteligência artificial generativa com a busca precisa na base de dados proprietária da empresa para evitar alucinações.

Exemplo Prático: O assistente de IA responde à dúvida do colaborador citando exatamente o parágrafo do manual interno de normas da companhia.

Ver serviço relacionado ↗

29. Chatbot com IA

Definição: Assistente conversacional que compreende áudios e textos em linguagem humana, superando os robôs tradicionais de menu numérico engessado.

Exemplo Prático: Atendimento receptivo de clínica médica que compreende 'Preciso de uma consulta com cardiologista na quinta de manhã'.

Ver serviço relacionado ↗

30. TCO (Total Cost of Ownership)

Definição: Custo Total de Propriedade: a soma de todos os custos diretos e indiretos de adquirir, operar e manter um software ao longo de vários anos.

Exemplo Prático: Comparar o valor acumulado de 3 anos de licenças SaaS por funcionário com o investimento único de criar um sistema próprio.

Ver serviço relacionado ↗

31. Lock-in de Fornecedor

Definição: Situação de dependência onde a empresa fica refém de uma única plataforma proprietária porque migrar para outra seria inviável ou proibitivo.

Exemplo Prático: Plataformas que cobram valores abusivos para exportar a base de clientes da empresa quando ela decide cancelar o contrato.

Ver serviço relacionado ↗

32. White-label

Definição: Produto ou serviço desenvolvido por uma empresa que outras empresas podem rebrandear e comercializar com sua própria marca.

Exemplo Prático: As 4 plataformas prontas da Branapi (BET, Gateway, Infoprodutos e BaaS) que operam com a identidade e domínio do cliente.

Ver serviço relacionado ↗

33. Gateway de Pagamento

Definição: Sistema que conecta um site de vendas ou app às adquirentes e bancos para processar transações de cartão de crédito, boleto e PIX.

Exemplo Prático: Infraestrutura de checkout própria desenvolvida para reduzir taxas de intermediação e realizar split de pagamentos.

Ver serviço relacionado ↗

34. BaaS (Banking as a Service)

Definição: Modelo que permite a empresas não-financeiras oferecerem serviços bancários (contas digitais, cartões e emissão de cobranças) sob sua marca.

Exemplo Prático: Uma rede de varejo que cria sua própria conta digital para fidelizar clientes e oferecer crédito próprio.

Ver serviço relacionado ↗

35. Multi-tenant

Definição: Arquitetura de software onde uma única instância da aplicação atende múltiplos clientes ('tenants') mantendo os dados de cada um rigorosamente isolados.

Exemplo Prático: A arquitetura padrão para plataformas SaaS onde centenas de empresas usam o mesmo sistema na nuvem com total privacidade.

Ver serviço relacionado ↗

36. UX/UI Design

Definição: UX (User Experience) foca na jornada, facilidade e eficiência de uso; UI (User Interface) foca na estética visual, tipografia e identidade das telas.

Exemplo Prático: Projetar um painel corporativo escuro com tipografia grotesca onde o operador encontra qualquer informação em menos de 2 cliques.

Ver serviço relacionado ↗

37. SLA (Service Level Agreement)

Definição: Acordo formal de nível de serviço que estipula prazos máximos para atendimento, resolução de problemas e uptime de servidores.

Exemplo Prático: Contrato que garante que o sistema ficará disponível 99,9% do tempo no mês e que chamados críticos são atendidos em até 1 hora.

Ver serviço relacionado ↗

38. Refatoração de Código (Refactoring)

Definição: Processo de reescrever e melhorar a estrutura interna do código sem alterar o comportamento externo visível pelo usuário final.

Exemplo Prático: Organizar um sistema lento para torná-lo 4x mais rápido e fácil de receber novos recursos nos meses seguintes.

Ver serviço relacionado ↗

39. Chão de Fábrica (PCP)

Definição: Planejamento e Controle da Produção: sistemas que monitoram em tempo real ordens de produção, máquinas, insumos e refugo industrial.

Exemplo Prático: Operadores registrando o status de fabricação em tablets industriais integrados ao estoque central da fábrica.

Ver serviço relacionado ↗

40. CTO as a Service

Definição: Contratação de liderança técnica executiva sênior sob demanda para guiar a arquitetura de software, escolha de tecnologias e gestão de produto.

Exemplo Prático: A Branapi atuando como o braço diretor de tecnologia da startup para apoiar os fundadores desde o MVP até a rodada de captação.

Ver serviço relacionado ↗
